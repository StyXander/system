## 三个归档文件夹

### `01_早期方案与计划书/`

选题阶段、旧版计划、创新草案、AI/组内评估等**过程材料**。

包括但不限于：

- 初步选题汇总、五项创新方案
- 旧版职责分工书、初步方案计划书
- 详细计划书早期稿 / 风险控制版 / 修改建议
- V2 / V2.1 评估报告（评估意见，不是最终正文）
- 选题前准备包、gpt 建议、参考文献候选清单

**不要**把这里的旧表述当成当前对外口径。
