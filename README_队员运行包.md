# 审迹智链本周网页成果运行说明

## 一步启动

1. 将压缩包完整解压到本机任意普通文件夹，不要只打开压缩包里的文件。
2. 双击根目录的 `启动审迹智链.bat`。
3. 第一次启动会创建本机运行环境并安装依赖；完成后浏览器会打开 `http://127.0.0.1:8000`。
4. 黑色启动窗口不要关闭；关闭它就会停止本地服务。

若没有自动打开浏览器，请手动访问 `http://127.0.0.1:8000`。请不要直接双击 `index.html`，否则网页无法调用本地后端。

## 包内功能与边界

- 可运行：标准股份 DEV_T0 开发样例、年度切换、来源台账、R1/R2确定性计算、规则勾选、人工复核本地留痕。
- 可查看：四份标准股份年度报告，供核对网页中的来源文件和页码。
- 尚未完成：RAG、公开资料自动检索、内部资料续分析、正式案例和正式效果评估。
- R1/R2目前是开发工程版；标准股份来源仍需团队专业复核，不能把页面结果当成审计结论。

## 模型 Key（本次内部包已包含）

本次“全量内部团队包”已经包含 `.env`，因此队员第一次启动后即可验证真实三Agent调用；不要自行把 Key 填进 `index.html`。

`.env` 内的 Key 仅供本项目组内部测试：不要转发给非队员、上传公开网盘/代码仓库、截图展示或用于其他项目。完成本轮联调后，建议由 Key 持有人到服务商后台更换一次 Key；未来提交给老师、评委或公开演示时，必须从交付物中删除 `.env`。

## 电脑要求

首次启动需要联网安装依赖，并需要 Python 3.10 或更高版本。若黑色窗口提示找不到 Python，请先安装 Python 后重新双击启动文件。
