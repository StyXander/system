# 审迹智链公开演示部署（Render 单网址）

目标：让访问者无需登录，直接打开一个 `https://……onrender.com` 网址查看网页并体验有限次数的 AI 分析。

## 部署前必须确认

1. 使用团队的私有 GitHub 仓库，不上传 `.env`、`backend/.venv`、`tmp` 或运行日志；根目录 `.gitignore` 已排除它们。
2. DeepSeek Key 只填在 Render 的环境变量中，不提交 GitHub、不写进网页，也不放进截图或竞赛材料。
3. 公开演示已默认限制为：同一访问地址每 15 分钟 2 次模型分析、全站每 15 分钟 40 次。确定性计算和页面查看不受影响。
4. 该限额是演示防护，不能替代正式的账户、网关和费用控制；发现异常调用应立即到 Render 删除/更换 Key。

## 最短部署步骤

1. 在 GitHub 新建私有仓库，例如 `audittrace-demo`，把本项目文件推送上去；不要提交 `.env`。
2. 登录 Render，选择 **New → Blueprint**，连接该私有仓库并选择根目录的 `render.yaml`。
3. 在创建页面填写 `DEEPSEEK_API_KEY` 的真实值；其他变量保持 `render.yaml` 默认值。
4. 创建完成后，等待构建结束。Render 会提供形如 `https://audittrace-demo.onrender.com` 的公开网址。
5. 用无痕窗口打开网址：确认首页能加载、`/api/health` 返回 `ready`、R1/R2可复算；再只做一次真实 AI 分析，确认三角色状态可见。

## 面向队员的说明

访问者无需注册或登录。由于这是公开演示，AI分析次数受到限额；额度用完时，网页仍可查看，确定性计算仍可运行，并会显示“公开演示调用次数达到临时上限”。

## 当前产品边界

线上版本只展示标准股份 DEV_T0 开发资料与 R1/R2 当前工程版。它不包含公开资料自动检索、RAG、内部资料上传、正式案例或审计结论。公开部署前请再次确认来源与专业口径已经由团队复核。
