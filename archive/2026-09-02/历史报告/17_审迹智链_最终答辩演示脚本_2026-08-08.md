# 审迹智链最终答辩演示脚本

## 演示目标

用一个审计师的真实工作场景说明：先用公开年报快速预筛，再在需要时补充资料；系统不把 RAG、程序筛查、AI 草稿和人工复核混成一个“黑箱结论”。

统一口径：AI 生成内容仅供审计计划阶段进一步核查，不构成审计结论或审计意见。

## 5 分钟流程

### 0:00—0:40 说明问题

演示词：

> 审计师第一次接触一家企业时，通常还没有内部账龄、期后回款和合同资料。审迹智链先使用巨潮资讯网的公开年报，完成来源校验、RAG 建库和确定性预筛；之后内部资料可以作为补充证据继续进入复核链。

展示页面：`02 项目与资料`，说明只访问巨潮公开来源，并显示“正式采用、缓存或导出前仍需人工复核”。

### 0:40—1:40 预热企业热路径：中国海油

输入 `600938`，选择“继续完整分析（项目所有者已许可）”。

必须展示：

- 输入框先显示“已命中热缓存”；
- 2025 / 2024 / 2023 年度；
- 任务显示“复用已校验 PDF，本次未重复下载”；
- RAG 块数 904 和检索编号；
- 行业闸门 `energy / direct`，理由代码保留在结果中；
- 自动进入完整分析结果摘要，展示真实 `run_id`，不要求用户复制编号。

演示词：

> 这次不是重新下载三份年报，而是核对公司、年度、来源指纹、RAG 版本和字段版本后复用快照。因此常用企业进入结果页很快；需要最新公告时才勾选强制刷新。

### 1:40—2:40 查看结果与边界

进入结果摘要或 `04 分析工作台`，展示：

- R1 程序筛查状态；
- 营业收入增速、应收账款增速、增速差和绝对变动；
- 账龄结构、期后回款、信用政策、合同条款等数据缺口；
- 资料索取清单；
- “未形成程序风险候选不等于无风险”提示；
- PDF 页码、证据编号、SHA-256 和官方 URL 的回查入口。

演示词：

> 系统输出的是可回查的审计计划线索，不是审计意见。没有程序候选，只能说明当前规则和当前公开数据没有形成候选，不能说企业没有风险。

### 2:40—3:30 金融行业闸门：中国人寿

输入 `601628`，选择“只下载 + RAG”。

必须展示：

- 年报与 RAG 正常完成；
- 行业组 `financial`；
- 适配等级 `not_applicable`；
- 当前 R1/R2 不适用，不显示空白的制造业指标；
- 仍可进入原文检索和资料台账。

演示词：

> 金融企业不是年报不存在，也不是下载失败，而是当前销售与收款规则没有金融专用口径。因此系统保留公开资料和 RAG 路线，明确跳过不适用规则。

### 3:30—4:20 新企业冷路径

输入一个不在 50 家白名单中的新证券代码，保持默认实时路径。

展示 11 步真实状态：企业确认、公告搜索、全文选择、PDF 下载、来源校验、案例登记、RAG、烟测、字段候选、字段闸门、分析 API。

演示词：

> 白名单只是加速，不是封闭名单。数据库外的企业仍然可以从巨潮搜索开始；成功完成校验后，系统会把新的公开快照写入目录，下一次再走热路径。

### 4:20—5:00 可复现与交付边界

展示仓库中的：

- `backend/cache_seed.example.json`：50 家可重复预热名单；
- `backend/cache_seed.lock.json`：50/50、三年快照的元数据锁定清单；
- `scripts/export_cninfo_cache_manifest.py`：从本地目录导出锁定清单；
- GitHub `v1.2.0` Release。

结束词：

> 这套系统把公开来源、确定性计算、RAG 检索、模型边界和人工复核分层保存。它的价值不是替审计师下结论，而是让审计师更快知道先查什么、缺什么、证据在哪里，以及哪些规则当前不应该运行。

## 失败演示口径

- 巨潮网络失败：显示失败原因和重试入口，不显示假完成。
- 年报存在但技术解析失败：显示“年报存在，解析待适配”和实际命中页码。
- 行业未知：不自动放行当前规则，保留 RAG 和人工确认入口。
- 缓存过期：显示校验时间和过期状态；需要最新公告时使用强制刷新。
- 服务重启中断预热：批次报告标记 `SERVICE_RESTART_RECOVERY`，不会永久停在“进行中”。
