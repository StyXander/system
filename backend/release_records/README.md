# AuditTrace 发布记录

此目录只保存经批准、可公开验证的最小发布事实。历史 `outputs/` 目录保持原样，
不把模型原文、私密底稿、API 密钥或未授权评分复制到发布包。

`r1_signoff_20260825_r2.json` 是已登记签字记录的字节副本。服务启动时仍会校验
规则规范串、源文件 SHA-256 和签字载荷；任何代码口径变化都会返回
`signoff_stale_requires_reapproval`，不会自动补造人工批准。

每个新评估目录可包含 `raw_records.jsonl` 和冻结 `dashboard.json`。原始记录只允许
追加写入；初始化记录不代表模型运行或人工评分。若追加真实 B0-B3，必须使用新记录
编号保存 task/run ID、模型、调用次数、角色状态、失败码和响应哈希，不覆盖历史目录。
