# 混合核验实施与验证

基线：`9d60fa0af43b76582839c5f60c9a9ee39a4d1b1d`。开发分支：`codex/hybrid-connectivity-20261018`。

本轮接续中断的竞品调研和开发指令，实施了程序计算与AI意见并行保存的主链。未合并主分支、未部署，也没有真实模型调用。完整方案及18项公开资料见同目录《混合核验开发指令》。

## 已完成的代码通路

1. 新增独立 `AIAnalysis`：意见、支持和反证、假设、替代解释、下一步、来源与输入指纹。正式计算和人工处理保持独立。
2. 模型可以提交语义关系类型、既有计算模板的选择理由、变量绑定和条件；程序生成计算方案记录并复算。相关、重合或不同指标不能进入同值公式。
3. 新增来源绑定的调节建议：模型只给披露ID与方向，程序取回金额、检查量纲和重复计入，生成独立场景调节表。其闭合不改变正式计算状态。
4. 按每项缺失条件召回材料，保留成员及已引用的调节、主张片段。A2和A3每批最多8项，默认每角色最多4批，`CONNECTIVITY_MAX_ROLE_BATCHES`可配置为1—8。记录未处理关系及预算原因，不能声称已读全文。
5. A3增加综合研判输出，不再只生成资料索取问题。意见引用可逐字核验，数值可以来自本项源证据和程序计算；匹配原句不等于业务含义已被独立确认。
6. 文字主张可以绑定连续两期披露，程序计算方向与变化幅度；语义、边界与分母仍由AI结合材料分析。
7. 组成候选不再以“先加平”为前置要求。自动支持完整性目前限定在有定义证据的资本化/费用化两分法；不同物理位置不再自动证明业务分类互不重叠。
8. 同签名更新保留既有有效证据、冲突、调节及复核字段。输入变化后旧AI意见显示需重新分析，用户采纳或驳回意见会创建子版本，保留原意见，不提升正式状态。
9. 工作台增加AI意见、场景调节、计算方案与文字方向结果，概览分别统计关联、程序结果、AI意见和待查问题。旧结果没有AI内容时明确显示未生成。
10. JSON、CSV、Word及页面打印包含相关结果；JSON同源检查增加AI意见与场景字段校验。静态资源版本升级，避免浏览器继续使用旧脚本。

新模块是 `backend/app/connectivity_intelligence.py`，复用现有Decimal、数值算子、任务台账、来源登记和配额，不新增模型供应商、数据库或Agent框架。

## 已执行验证

关联核验相关测试共 **85项通过**，其中新增12项覆盖场景调节、伪造引用/数值、重复调节、同签名更新、组成不平、文字方向、定向材料预算、三角色离线全链、恢复和导出、AI意见采纳及供应商工具合同。两条警告分别来自测试环境弃用提示和既有测试样本的序列化提醒，不作为专业准确率指标。

运行命令：

```bash
PYTHONPATH=backend python -m pytest backend/tests/test_connectivity*.py -q
node --check assets/official-v4/connectivity.js
git diff --check
```

离线全链使用明确命名的 `OFFLINE_TEST_DOUBLE`，没有连接真实模型，不能据此评价提示词的实际分析质量。

合成保存结果的DOM检查已通过：AI意见、调节表、导出入口和采纳操作正常，采纳后计算状态保持原值。验证脚本为 `scripts/verify_connectivity_hybrid_dom.cjs`，需要测试依赖happy-dom及明确标记为synthetic的结果JSON。它不验证真实浏览器像素布局。

Chrome安装返回非ZIP内容，未能完成真实浏览器截图和多视口布局复核。这一项保持未验证，不能将DOM检查称作视觉验收。

## 真实报告对照

四份登记PDF已从登记的官方URL取得，并逐份通过SHA-256校验。旧基线和开发版本使用同一原件、同一主题、同一纯计算模式：

| 报告对 | 基线候选/新候选 | 基线正式一致/新正式一致 | 基线条件试算/新条件试算 | 真实模型调用 |
|---|---|---|---|---|
| 五粮液2025 | 8 / 8 | 2 / 2 | 4 / 4 | 0 |
| 宝钢2025 | 9 / 9 | 0 / 0 | 9 / 9 | 0 |

此处宝钢的9项是本次纯计算运行结果，与历史截图含模型建议的16项不属于同一执行模式，不能直接比较。完整源哈希和统计见 `2026-10-18_登记报告纯计算对照.json`。

真实报告的确定性结果没有因本轮新增AI意见而被抬高。合成用例已验证：缺范围依据时，150万元候选差额可由来源中的150万元设备投入作条件桥接，生成独立意见和调节表，正式差额仍为空。这是机制验证，不能移植为对五粮液或宝钢的实际判断。

零模型实报核验可复现：

```bash
python scripts/verify_connectivity_hybrid.py --output outputs/hybrid-verification
```

首次运行需能访问登记原件；没有原件不能用其他版本替代。
