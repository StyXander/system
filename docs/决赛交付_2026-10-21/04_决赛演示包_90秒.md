# 决赛90秒演示脚本

这是时间预算，不是完整现场计时成绩。原版声称明细0.8秒、原文1.5秒缺少证据，已撤回。最新浏览器实测见outputs/integration-20261021/browser_repair.json；失败或缺项不能写成通过。

| 时间 | 操作与讲解 |
|---|---|
| 0–15秒 | 打开预跑的五粮液真实记录，明确说明“历史运行回放”，展示公司、报告期间与执行模式。 |
| 15–30秒 | 展示程序六档：正式一致、假设内相容、有限支持、依据不足等。数字以这次真实运行显示为准。 |
| 30–55秒 | 点击“查看条件与计算”，展示研发比例算式、未满足前提及精度假设；条件试算不宣称正式一致。 |
| 55–75秒 | 点击“原页PDF”，等待真实页图加载，说明引文和页码；关闭后回到关系。 |
| 75–90秒 | 展示待补材料与AI意见分栏，说明程序不接受模型自证。 |

预跑纯计算不能证明AI语义召回，若展示AI必须另选确实调用模型的历史记录，标明模型、运行时间及partial状态。contradicted表示模型主张存在矛盾，不是有效反证条数。

应急：模型不可用时切纯计算并标明未调用；网络故障使用预先保存的历史截图并标注回放。图片可展示历史引文，不能替代此次原文可访问验收。
演示前在同一浏览器验证：打开记录、关系明细、原页图、刷新恢复、历史恢复。任一步失败应保留失败记录，不能靠提醒“不要刷新”算通过。
