# 操作手册

## 启动

按仓库README安装依赖，使用既有start.sh或start.bat，正式入口为backend.app.connectivity_app:app。模型配置使用部署环境的密钥配置。公开演示方式、持久化和访问权限沿用既有设置。

## 核查

1. 在首页进入核查工作室，选择或搜索企业及报告年度。
2. 登记或选择同一企业资料集合，核对来源、期间及观察时点。
3. 建立候选档案，选中一个具体事项。
4. 使用五智能体调查，查看真实阶段、角色和工具回执。
5. 分别查看项目关系、金额口径、支持与反证，回到原PDF页核对。
6. 将尚未取得证据的问题留在资料需求清单，按权限记录人工意见。
7. 导出Word、CSV或JSON，核对与当前结果版本一致。

## 历史和失败

顶部任务档案读取服务端记录，正在运行任务与历史浏览分开。任务超时或部分完成时查看原因及已保存结果，使用已有重试入口。不要把历史任务当成本次新执行。

## 宝钢专项

顶部宝钢专项核查展示原件、项目范围、表格调节和历史调查回执。总工程与子工程范围需分别确认，模型建议与程序计算分列。
