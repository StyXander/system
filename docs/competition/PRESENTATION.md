# PPT内容与演示脚本

1. 项目与具体核查问题，展示真实披露及财务附注。
2. 用户现行工作与已取得的访谈记录，未访谈部分标待验证。
3. 技术差异，区分事项关系、金额口径和证据支持。
4. 五智能体与程序规则的职责，显示实际工具记录。
5. 独立测试协议与结果，只填已执行数据。
6. 宝钢案例，从总工程与子工程身份核对开始，查看范围差异、金额调节和证据。
7. 失败及适用边界，显示补证需求。
8. 实际试用与知识产权办理状态。

## 约三分钟实操视频脚本

打开工作室并选择报告，建立候选事项。进入一个事项，展示身份及口径，查看支持证据和反证，再回到原页，最后导出工作底稿。运行等待可以加速或使用明确标识的历史回放。视频时长以赛事要求为准。

## 问答准备

为何选择发明制作、方法相对现有技术的变化、多智能体是否优于同预算单模型、金标如何形成、失败如何处理、公开报告与内部证据的边界、试用和知识产权实际进展。所有问题按当前证据回答。
