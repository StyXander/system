# 审迹智链——跨报告财务关联证据核验系统

## 问题与对象

企业绿色转型事项散见年报和可持续发展报告。项目总体预算、本期工程增加、累计投入和现金付款之间存在口径差异。软件面向财务及ESG编制复核和审计鉴证项目的前期证据整理。

## 技术实现

系统使用登记报告及原件哈希建立多年资料集合。A1识别事项，A2调查财务路径，A3追踪跨期进展，A4检索竞争解释，A5综合复核。主体、期间、定义、范围、单位和计量基础约束先于数值调节。直接陈述、计算、模型假设及人工采用分别记录。

程序维护项目关系和金额可比性两个维度。数值复算仅操作已定位的数值，检查期间、范围、单位、币种和重复操作数。计算完成后保留条件试算状态，语义仍需专业复核。

## 已落实的实验支持

比较入口显式选择一个事项，保存案例映射、预算及完整运行文件。固定证据模式冻结输入集合并拒绝新增检索和数值定位。宝钢表格预处理向各架构统一提供，比较运行统一关闭额外定向反馈。生产工作流仍按原设置执行。

## 前端

核查工作室采用顶部导航、横向阶段线、文档式工作区域和石墨、暖白、蓝灰配色。原有资料选择、任务、历史、证据和导出事件继续使用现有接口。

## 效果与先进性

独立人工金标和真实模型比较尚待完成。现有工程测试只用于说明实现行为。RAG、多智能体及页码引用已有技术基础，拟验证的贡献集中于口径约束、财务关系核验和证据驱动修订。实际比较结果取得后补充方法差异、计数、成本及适用条件。

## 应用及成果

真实用户试用和权属登记以取得的材料为准。公开报告核验支持披露关联分析，具体入账真实性仍依赖适当业务材料。
