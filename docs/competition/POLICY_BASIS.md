# 政策依据与功能对应

| 政策 | 对应需求 | 软件支持 |
|---|---|---|
| 财政部《企业可持续披露准则——基本准则（试行）》第5条 | 报告主体一致 | 主体和范围核对 |
| 同准则第6条 | 可持续信息与财报信息的关联、数据与假设的协调和差异说明 | 项目关系、金额口径和差异证据 |
| 同准则第7条 | 数据收集、验证、分析及报告系统 | 来源、处理、核验和导出 |
| 上交所第14号指引 | 适用主体、报告期间及信息质量要求 | 资料登记和期间核对 |

基本准则正式文件成文于2024年11月20日，官网于12月17日公开发布。5月发布的是征求意见稿。基本准则在实施范围及要求另作规定前由企业自愿实施。沪深北各所规则须分别核对适用范围，北交所已核对版本为自愿披露。政策支持业务需求，专业效果需要实测。
