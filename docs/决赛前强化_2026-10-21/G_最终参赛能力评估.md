# 交付物 G：最终参赛能力评估

评分原则：以本轮实际代码与实测结果为准；没有证据的能力按"未验证"处理，不给同情分。

| 维度 | 分数 | 评价重点 |
|---|---|---|
| 业务真实性 | **7.5** | 是否解决现实存在的专业需求 |
| 专业核验深度 | **7.5** | 是否超越简单数值核对 |
| AI 能力 | **5.5** | 是否具有有效的语义分析与推理 |
| 多 Agent 有效性 | **4.0** | 协作与复核是否产生额外价值 |
| 创新竞争力 | **6.5** | 相比传统方案是否有明确增量 |
| 准确性与幻觉控制 | **6.0** | 是否有可复现的数据证明 |
| 证据可信度 | **8.0** | 结论能否由原文核实 |
| 演示说服力 | **5.5** | 评委能否迅速看到真实价值 |
| 工程稳定性 | **6.5** | 是否可以稳定完成现场操作 |
| 实际应用潜力 | **6.0** | 是否有清晰的真实业务边界 |
| **综合** | **6.3 / 10** | — |

## 逐项理由

### 业务真实性 7.5

**加分**：跨报告同一指标的一致性核验是真实存在的阅读与复核需求；系统面向的是"两份已成稿报告之间"的比对，不是虚构场景。5 对真实公开报告可跑通，共 10 份原件登记了 URL 与 SHA-256。
**扣分**：只有研发、环保、强度三类事项，未覆盖财务与 ESG 的其他常见关联（职工薪酬、产量、税收优惠等）；没有真实用户或事务所试用记录。

### 专业核验深度 7.5

**加分**：五项前提（主体/期间/定义/范围/单位）逐项要求原文依据；区间算术、残差门禁、假设试算、加性调节、比例逆分母都真实实现；本轮又补上了"其中："组成行、跨报告比例分子分母、定义句限定语。
**扣分**：组成关系只支持资本化/费用化两分法；"范围"前提在真实年报上可达性极低，导致 5 对真实报告 29 项候选无一形成正式结论（3 项仅为"假设下相容"，其余不可比）；多位置冲突按政策不升级为结论。

### AI 能力 5.5

**加分**：A1/A2/A3 三个角色有明确的契约、白名单、字段剥离与结论分级；模型只能提"关系与主张"，不能提交计算与结论；本轮把"AI 自封前提"从机制上关掉。
**扣分**：**本轮没有调用真实模型**（无 Key），AI 的实际输出质量未被验证；知识库消融显示对结果无影响；A3 无否决权；提示词仍是"任务描述 + JSON 契约"，没有工具调用或自主规划。

### 多 Agent 有效性 4.0

**加分**：三个角色职责不同，A2 能看到 A1 的计算结果并提反证，A3 独立研判；跨角色信息传递有真实数据流（`intelligence_trace`）。
**扣分**：**不存在 A4—A7**；没有"下游发现并退回上游"的纠错闭环；消融实验（前次审查）显示三角色与单模型的最终 checks、criteria、formal 完全一致——多 Agent 目前证明不了边际价值。答辩必须主动说明这一点，而不是包装成"七智能体"。

### 创新竞争力 6.5

**加分**："口径兼容性先于数值比较"+"AI 主张必须被程序复核"这两点，确实比"上传两份 PDF 问大模型"多了一层可审计机制；有 24 个对抗样本与前后对照可以作为证据。
**扣分**：这两点的技术门槛不算高（规则 + 校验 + 分级），容易被评委认为"工程实现而非算法创新"；没有与任何商业系统或普通模型的实测对比。

### 准确性与幻觉控制 6.0

**加分**：24 个对抗样本 15→22，差异查全 50%→75%，错报 1→0；AI 自封前提、重复扣减、舍入误报都有针对性测试；引用 100% 可回查。
**扣分**：**样本是合成的、由同一团队构造与评判**，不能当真实准确率；真实报告无标注、无准确率；没有真实模型的幻觉率数据；仍存在"引文 2 字即可通过"的弱校验（解释文本层）。

### 证据可信度 8.0

**加分**：这是系统最扎实的一环。每条披露有页码、坐标、原文、证据强度；条件引文逐字校验；导出强制附加声明；模型不能提交页码与数值。
**扣分**：印刷页码未映射（只有 PDF 页码）；跨报告范围的证据仍以报告级声明为主，不能证明指标级边界。

### 演示说服力 5.5

**加分**：结果页分栏清楚（程序结论 / AI 意见 / 人工处理），原文阅读器可用，"为什么不下结论"讲得清。
**扣分**：**真实案例上没有"确认差异"可展示**，这是硬伤；演示必须靠"证据链 + 缺口 + 修复前后对照"来讲，节奏偏慢；线上冷启动 56 秒对现场是实质风险；页面未区分实时与历史结果。

### 工程稳定性 6.5

**加分**：任务状态机、阶段推进、取消、失败降级都有实现；模型失败不影响规则结果；任务台账外置，刷新可恢复。
**扣分**：免费实例冷启动 56 秒；本机全量测试有 247 个环境性 error（前后一致），无法给出"全绿"结论；前端未做本轮真实浏览器验收。

### 实际应用潜力 6.0

**加分**：边界清楚（不做审计结论、不做鉴证），输出物（证据清单与缺口）是事务所真实会用的中间产物；隐私与最小传输有设计。
**扣分**：要成为业务系统，必须先解决"范围前提可达性"与"真人标注准确率"；当前只覆盖 3 类事项、5 对报告。

---

## 一句话结论

**这是一个"证据结构做得比结论更扎实"的系统。** 它最值得讲的是"怎么证明能不能比、怎么防止 AI 自我认证"；最不该讲的是"七智能体""RAG 提升准确率""已发现企业差异"。按当前真实能力，综合 **6.3/10**：进决赛圈够用，但离"专业可信"还差一次真实标注集与一次真实模型验证。
