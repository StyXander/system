# AI3｜5–10 秒理解 + 3 分钟任务测试：脚本与记录模板

> 用途：验证“第一次访问的评委能否在 10 秒内说出产品用途，专业使用者能否在 3 分钟内找到下一步处理依据”。
> 状态：**测试材料，尚未执行真人测试**。没有真实参与者时不得填写结果，也不得写成“5 人测试通过”。

## 一、被试与条件

| 项 | 要求 |
|---|---|
| 人数 | 5 名不熟悉本项目的人（建议 2 名会计/审计方向、1 名 ESG/环境方向、2 名非财务背景） |
| 设备 | 与被试日常一致的电脑或手机；至少 1 人使用 390px 宽手机 |
| 环境 | 无痕窗口，不提前介绍产品；主持人只读脚本，不解释界面 |
| 数据 | 使用已登记真实报告的任务链接（五粮液 2025）。若使用历史任务，须当场说明“这是已保存的历史结果” |
| 记录 | 录屏 + 计时 + 原话摘录；截图保存到 `docs/ai_handoff/screens/usability/` |

## 二、5–10 秒理解测试（首页）

主持人念：

> “请看一眼这个页面，然后用自己的话告诉我：它是做什么的？你会点哪里开始？”

| P2 |  |  |  |  |  |  |
| P3 |  |  |  |  |  |  |
| P4 |  |  |  |  |  |  |
| P5 |  |  |  |  |  |  |

判定线（事先约定，不可事后调整）：
- 5 人中 ≥4 人能在 10 秒内说出“两份报告/年报与可持续报告”+“核对/比较”，且 0 人认为是评级或荐股产品 → 通过。
- 出现“这是 ESG 评级/碳排风险平台”即记为一次误读。

## 三、3 分钟任务测试（结果页）

给被试的任务卡（只给这张卡，不给口头提示）：

1. 打开这条核验记录，说出本次一共有几项关系，其中几项完成了正式复算、几项还不能判断。
2. 找出最值得先看的一条关系，说明它为什么不能直接比较（或为什么可以）。
3. 打开这条关系引用的原页，确认数字出处。
4. 说出下一步应该向公司索取什么材料。
5. 回到首页，再通过历史记录重新打开这条任务。

记录：

| 编号 | 完成步骤（1–5） | 总用时 | 卡在哪一步 | 误读（把“依据不足”读成“没问题”等） | 是否找到补证任务 | 备注 |
|---|---|---|---|---|---|---|
| P1 |  |  |  |  |  |  |
| P2 |  |  |  |  |  |  |
| P3 |  |  |  |  |  |  |
| P4 |  |  |  |  |  |  |
| P5 |  |  |  |  |  |  |

关键错误分类（用于定位设计问题）：
- E1 把“依据不足·不可比”读成“没有问题”
- E2 把 AI 倾向当成程序结论
- E3 找不到原文/不知道点哪里
- E4 看不懂“正式/条件试算/有限支持”的区别
- E5 历史或深链恢复失败
- E6 手机上按钮被遮挡或点不到
