# 竞品与本轮创新边界

2026年10月19日核对官方页面，以下为能力边界比较，未进行竞品实机测试或精度排名。

| 工具 | 官方页面支持的能力 | 与本项目的边界 |
| --- | --- | --- |
| Workiva | 财务、可持续等报告协作与数据关联；其AI可辅助发现不一致 | 不能把报告关联、引用或AI辅助单独称作首创。本项目仅验证登记公开PDF的比较条件和关系复算 |
| MindBridge | 审计计划任务包含认定、审计领域等信息，计划可导出 | 不能把认定映射、待查任务或导出称作独有。本项目当前不以交易全量审计风险评分为主线 |
| Diligent ESG | ESG数据收集、计算和报告管理 | 不能宣称自动计算或可追溯ESG报告为独创。本项目仍是已登记报告专项核验原型 |

来源：[Workiva报告平台](https://www.workiva.com/solutions/sec-reporting)、[Workiva AI可持续报告](https://support.workiva.com/hc/en-us/articles/48891676353428-Use-Workiva-AI-for-sustainability-reporting)、[MindBridge任务详情](https://support.mindbridge.ai/hc/en-us/articles/360058198653-Audit-plan-Task-details)、[计划导出](https://support.mindbridge.ai/hc/en-us/articles/360058198713-Audit-plan-export)、[Diligent ESG](https://www.diligent.com/products/diligent-esg)。

当前可讨论的组合是结构化比较条件、分级复算、可反驳解释和具体补证动作。其增量须由同样本、同模型与尽量同证据预算的对照验证。17项合成样例只提供程序预期，不提供普遍专业正确率；本轮单模型、旧三阶段和升级三阶段组未运行。
