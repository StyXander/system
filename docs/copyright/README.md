current包含源程序Word、纯文本、逐显示行到原文件行号的CSV映射，以及文件哈希和完整程序编排顺序。生成器从确定顺序的真实源程序中取前后连续选段，不为凑固定结尾删除空行或补造代码。长行仅排版折行，并在映射中保留原行号与段号。
