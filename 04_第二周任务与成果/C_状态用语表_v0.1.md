# C：状态用语表 v0.1

> **用途：** 第二周（G1）组内统一进度与专业状态表述，避免「代码跑通」与「专业已核」混用。  
> **对齐：** 第二周任务分工、职责分工书 V3.1、主计划书 V2 风险表述边界。  
> **状态：** 草拟完成，供全组即日起使用；若主计划书或老师另有明确术语，以更新后的正式口径为准。  
> **日期：** 2026-07-20

---

## 一、四类核心状态（必须全员统一）

| 术语 | 定义 | 谁可以标 | 适用场景 | 不得用来表示 |
|---|---|---|---|---|
| **草拟** | 初稿已写出，尚未经对照准则、PDF 原文或组内专业要求核对 | 作者本人 | 规则说明、页面文案、数据台账初稿、计划书段落 | 不得等同于「已实现」或「可提交验收」 |
| **已复核** | 经**人工**对照专业要求、PDF 原文、准则条款或既定检查表完成核对 | 非原录入人优先；至少有明确复核人与日期 | 规则逻辑、财务数字、页码引用、风险卡专业措辞 | **不等于**代码已写完；**不等于**实验结果通过 |
| **已实现** | 对应功能已在约定网页目录中编码完成，并可在本机正常打开与运行 | 队长（实现）+ 另一人可打开确认 | 技术功能层：公式计算、年份切换、异常拦截、来源展示 | **不等于**专业已复核；**不等于**验收通过 |
| **已测试** | 使用**正常样例**与**异常样例**验证过运行结果，并留有测试记录 | 队长写记录，A/B/C 可交叉复测 | 计算正确性、四类异常拦截、年份切换、evidence_id 回指 | **不等于**正式实验结论；**不等于**舞弊识别准确率 |

**特别说明（第二周反复强调）：**

1. 「代码跑通」→ 最多标 **已实现**，不能写 **已复核**。  
2. 「数字已回 PDF 抽查」→ 若尚未由**另一名队员**签字复核，仍不得写 **已复核定稿**。  
3. 「样例可算出增长率」→ 若未覆盖异常输入，不得标 **已测试**。  
4. 三个状态可以同时出现在同一对象上，但必须分开写，例如：  
   > R1-L1 公式：**已实现**；标准股份 2025/2024 四数：**已回 PDF 抽查，交叉复核待完成**；异常拦截四场景：**已测试**（见队长测试记录）。

## 二、页面与数据相关状态（录入层）

| 术语 | 页面/台账含义 | 何时使用 |
|---|---|---|
| **待接入** | 该行尚未填写任何有效内容 | 空白行 |
| **部分录入** | 已填部分字段，但数值或来源定位不完整 | 缺 evidence_id、页码、文件名等任一项 |
| **完整录入，待复核** | 数值 + 来源定位（含 evidence_id）齐全，尚未完成另一人回 PDF 核对 | 可进入计算与候选卡草稿，但仍须人工复核 |
| **公司/年度不匹配** | 当前数字绑定的公司或年度与项目设定不一致 | **必须阻断计算**，不得静默沿用旧数 |
| **晚于 T0，已阻断** | 来源披露日晚于分析截止日 T0 | 不得纳入本时点计算 |
| **开发/演示用** | 数据或粗扫记录仅用于开发演示，非正式留出案例、非正式抽检结论 | B0 粗扫、内置样例标题必须标注 |

## 三、风险卡与人工处理状态

| 术语 | 含义 | 边界 |
|---|---|---|
| **候选现象** | 按规则方向出现「值得进一步了解」的信号 | 不是舞弊认定，不是风险等级 |
| **待核查** | 建议项目组纳入后续了解/资料索取范围的事项 | 须保留正常解释与资料缺口 |
| **仅完成计算** | 数字与公式已复算，但方向规则未触发候选 | 不代表「无风险」 |
| **未复核** | 人工尚未选择处理意见 | 默认状态 |
| **保留为待核查候选** | 人工决定保留该线索供后续跟进 | 人作决定，系统不代签 |
| **降级** | 人工认为信号权重下降，但仍可保留痕迹 | 须写依据；**系统不得因找到 MD&A 解释自动降级** |
| **暂缓** | 人工决定本阶段不推进 | 须写依据或缺口 |

## 四、规则与工程版本用语

| 说法 | 正确用法 | 错误用法 |
|---|---|---|
| 草案 - 尚未实现 | R2 等仅文档、未上网页的规则 | 写成「系统已支持 R2」 |
| 工程版 / 可执行版 | 字段、公式、触发条件、异常处理写清，可供编程 | 把「可执行」写成「已上线并验证有效」 |
| 拟 / 计划 / 建议 | 主计划书中未完成事项 | 写成「已完成实验」「准确率已达××」 |
| 待核验 / UNKNOWN | 原件页码、准则页次无法核对时 | 猜测页码或编造出处 |

## 五、禁用与慎用（与专业边界相关）

| 类型 | 示例 | 处理 |
|---|---|---|
| **禁用（对外/页面）** | 发现舞弊、公司造假、舞弊概率、审计意见、建议买入/卖出 | 一律不出现于产品输出 |
| **慎用（须改写）** | 高风险、重大错报已存在、持续经营重大不确定性（续聘场景） | 改为「待进一步了解」「可能影响审计资源安排」等平实表述 |
| **允许** | 待核查线索、资料缺口、可能的正常解释、建议索取资料、候选认定（仅审计计划场景） | 须配套 evidence_id / 来源回指 |
