## 1. 风险卡正文（五段结构）

### 1.1 发现了什么现象

**方向触发时（应收增速 > 收入增速）：**

> {本年} 年，{公司名称} 应收账款增速为 {arGrowth}，营业收入增速为 {revenueGrowth}，前者高出 {gapPp} 个百分点。按 R1 当前方向规则，形成「待进一步了解」的候选现象；是否保留须人工复核。

**方向未触发时：**

> {本年} 年，{公司名称} 应收账款增速为 {arGrowth}，营业收入增速为 {revenueGrowth}。按当前两个指标的方向，本次未形成 R1 候选；这不代表不存在其他收入确认相关风险。

**卡片标题：**

| 情形 | 标题 |
|---|---|
| 触发 | 应收账款增速高于收入增速，建议进一步了解 |
| 未触发 | 本次未出现「应收增速高于收入增速」的方向 |

**方向标签：**

| 情形 | 标签文案 |
|---|---|
| 触发 | 候选现象 |
| 未触发 | 仅完成计算 |

### 1.2 为什么值得进一步了解

> 收入与应收账款的变动关系，需要结合信用政策、结算周期、客户结构变化和期后回款进一步解释。当前计算本身不能证明收入确认存在错报，也不能证明不存在错报。

### 1.3 可能的正常解释（至少保留 4 条方向）

页面展示为标签 + 一句限定：

- 新增大客户或客户结构变化  
- 信用政策或结算周期调整  
- 季节性因素导致年末应收暂时增加  
- 行业整体账期拉长  

限定句：

> 以上仅为待核验方向，不代表系统已检索到支持证据，也不自动消除候选。

### 1.4 当前资料缺口

> 目前未在公开年报中完整取得：应收账款账龄明细、期后回款情况、主要客户合同关键结算条款摘要、大额销售明细。缺口以公开资料检索结果为准，不以「公司从不披露」作绝对表述。

### 1.5 建议向客户索取的资料

> 账龄明细表、期后回款记录、主要合同摘要、信用政策变更说明（如有）。取得资料后仍须人工判断，本周不提供自动上传续分析。

### 1.6 仅「审计计划」场景追加

> 候选认定（供项目组选择，不得机械全选）：收入的发生；应收账款的存在、权利和义务、计价和分摊。  
> 供项目组考虑的程序：检查账龄及期后回款，了解主要客户信用期变化，抽查主要合同的结算与验收条款。具体程序由项目组决定。

业务承接 / 续聘复核：**不显示**本段。  
续聘场景若需单独提示，可用：

> 可评估是否存在影响审计资源安排或续聘决策讨论的公开信号；系统不自动给出续聘结论。

## 2. 异常提示文案（四类必拦）

风格：清晰、温和、说明下一步；**不用感叹号、不用恐慌措辞、不暗示造假**。

### 2.1 必需字段缺失

**闸门标题：** 尚缺可计算的年报字段  

**闸门正文：**

> 请完整录入本年与上年的营业收入、应收账款。任一项为空或无法识别为数字时，系统停止计算，不会输出默认增长率。

**数据页行状态：** 部分录入 / 待接入  

### 2.2 年份错位（两类）

**A. 项目设定中本年与上年不连续**

**标题：** 本年与上年必须连续  

**正文：**

> 请将本年设置为上年的下一年度（例如 2025 / 2024）。年度关系未通过前，系统不进行增长率计算。

**B. 已录入数字与项目公司/年度不一致**

**标题：** 项目年度与数字不一致  

**正文：**

> 当前四项数字未绑定到所选公司与年度，系统已停止计算。请重新载入对应期间的开发样例，或按该期间重新录入资料与来源编号。

### 2.3 除数为零（上年金额为 0）

**标题：** 上年金额为 0，无法计算增长率  

**正文：**

> 上年营业收入或上年应收账款为 0 时，增长率分母无效。系统已停止计算，请核对是否录错年度或金额，勿用估算值代替。

### 2.4 缺少来源编号 / 来源定位不完整

**标题：** 数字已可计算，来源仍未通过  

**正文：**

> 请为四个数字分别补齐：来源编号（evidence_id）、来源文件、披露日期、PDF 页码、印刷页码与原文位置。缺少任一项时，不生成候选风险卡。披露日晚于分析截止日 T0 的资料将被阻断。

**来源旁注（证据列表区）：**

> 来源编号与页码用于回到年报 PDF 原文核对；请对照台账中的 evidence_id 打开对应文件与页码。

## 3. 来源标注区文案

### 3.1 数据表新增列说明

| 列名 | 旁注 / placeholder |
|---|---|
| 来源编号 | 如 STD_REV_2025；每个参与计算的数字一行一号 |
| PDF 页 | 阅读器实际页码 |
| 印刷页 | 页脚印刷页；没有则填「原件未标注」 |

表下提示：

> 不得猜测页码。找不到印刷页时填写「原件未标注」。来源编号须与统一来源台账一致。

### 3.2 风险卡「本卡引用的四项来源」展示格式

建议每行：

> **{字段中文}**　{金额} {单位}  
> 来源编号：{evidence_id}　｜　{文件名}　｜　披露于 {日期}　｜　PDF 第 {n} 页　｜　印刷页码：{…}　｜　{原文位置}

### 3.3 数据绑定提示（data-context-tip）

| 情形 | 文案 |
|---|---|
| 未建项目 | 请先保存公司与连续年度；数字只有绑定到对应期间后才能进入计算。 |
| 不匹配 | 当前数字与项目公司/年度不一致，已阻断计算；请重新载入或录入本期间资料。 |
| 匹配·样例 | 当前资料绑定：{公司} · {本年}/{上年} · 内置开发样例。公司或年度变化时不会沿用旧数字。 |
| 匹配·人工 | 当前资料绑定：{公司} · {本年}/{上年} · 人工录入区。 |

## 4. 项目页 / 数据页增量措辞

### 4.1 样例加载区

**标题：** 第二周开发样例（标准股份）  

**说明：**

> 支持 2025/2024、2024/2023、2023/2022 三组连续年度；数字、来源编号、文件名与页码整组绑定。样例仅供开发与演示，非正式冻结案例；另一名队员交叉复核完成前，不得写「已复核定稿」。

**按钮：** 载入开发样例  

### 4.2 数据页标题区

**标题：** 年报数据与来源台账  

**说明：**

> 每个参与计算的数字都须能回答：出自哪份 PDF、第几页、原文如何表述，并对应唯一来源编号。

### 4.3 风险页口径说明

> 本周只比较本年与上年的营业收入增速、应收账款增速及其差额；应收增速高于收入增速时形成待核查候选，**不自动判定风险等级，不设置固定百分点阈值**。  
> **暂不计算**应收账款周转天数：所需平均余额等字段未齐备时标注「该指标因缺少字段暂不计算」，严禁用估算值替代。

### 4.4 Toast / 轻提示（建议）

| 场景 | 文案 |
|---|---|
| 项目已保存 | 项目字段已保存在本浏览器 |
| 年度切换样例 | 已切换为 {期间} 开发样例；数字、来源编号与页码已同步更新 |
| 公司/年度变化清空 | 公司或年度已变化；旧数字和来源已清空，请录入本期间资料 |
| 数据可算 | 数据已保存并完成确定性计算 |
| 数据不可算 | 数据已保存，但因字段或分母问题停止计算 |
| 来源未过 | 计算已完成展示门槛检查：来源未通过，未生成候选卡 |
| 复核未过门槛 | 来源准入未通过，暂不能保存人工复核处理 |
| 清空确认后 | 本机保存的原型内容已清空 |

## 5. 推荐表述 vs 禁止表述（本周自查用）

| 推荐 | 禁止 |
|---|---|
| 应收账款增速高于收入增速，建议进一步了解信用政策与期后回款 | 公司可能存在收入造假 |
| 形成待核查候选 / 候选现象 | 系统已发现舞弊迹象 |
| 目前未在公开年报中找到×× | 公司从不披露×× |
| 不构成审计结论 | 审计意见为…… |
| 供项目组考虑的程序 | 建议投资者卖出 |
| 开发/演示用样例 | 已验证的正式案例结论 |
