## 一、本周队长做了什么

| 项 | 说明 |
|---|---|
| 工作目录 | 仅修改 `audittrace-local-static`，未改其他网页副本 |
| 数据接入 | 内置标准股份三组期间开发样例（B v0.2 口径：元、页码、文件名） |
| 来源编号 | 每行增加 `evidence_id`（如 `STD_REV_2025`），数据表与风险卡均展示 |
| 公式 | 程序自动计算收入增速、应收增速、差额；禁止手填结果 |
| 年份切换 | 改 本年/上年 后，已知样例整组切换数字+编号+页码；未知期间清空旧数 |
| 异常拦截 | 字段缺失 / 年份错位 / 除数为零 / 缺少来源编号 → 闸门文案，不静默出结果 |
| 文案 | 接入 C 第二周页面文案要点（边界声明、风险卡五段、异常提示） |

**公式口径（与第二周分工、计划书一致；不待 A 文档即可工程实现）：**

- 收入增长率 = (revenue_current − revenue_previous) / revenue_previous  
- 应收增长率 = (ar_current − ar_previous) / ar_previous  
- 触发方向：应收增长率 > 收入增长率 → 候选现象  
- **不设**固定百分点阈值；**不计算**周转天数（缺字段则暂不计算）

## 二、如何打开（给全组）

1. 打开文件夹：  
   `plan/outputs/数智会计竞赛/03_第一周任务与成果/audittrace-local-static/`  
2. 双击 `index.html`（推荐 Chrome / Edge）。  
3. 点击 **「载入开发样例」** → 自动进入数据页，可见四行数字与来源编号。  
4. 点 **「保存、计算并查看风险页」** → 查看增长率与风险卡/闸门提示。  
5. 若要测触发方向：在项目页把本年/上年改为 **2023 / 2022**，保存后样例会整组切换（该期间应收增速高于收入增速）。

**注意：** 浏览器本地存储键已升级为 `audittrace_week2_state_v3`。若仍看到旧表头，请强制刷新（Ctrl+F5）或清空本机内容后重开。
