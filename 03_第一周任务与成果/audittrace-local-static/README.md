# 审迹智链 AuditTrace · 本地静态开发预览（W2）

这是团队当前**唯一正式网页工作目录**（第二周任务分工约定）。页面使用纯 HTML、CSS 和 JavaScript，可离线打开，不要求 GPT 登录，也不会向外部服务上传录入内容。

> **边界：** 本系统仅生成待核查线索，不构成审计结论，不认定舞弊行为，不提供投资建议。

## 怎么打开

1. 进入 `03_第一周任务与成果/audittrace-local-static/` 文件夹。  
2. 双击 `index.html`。  
3. 建议使用 Chrome 或 Edge。  

如果浏览器限制双击页面的本地保存功能，可用本地静态服务器打开；页面本身仍不需要后端。

组内说明与验收材料见：`04_第二周任务与成果/队长_W2集成与验收说明_v0.1.md`。

## 第二周可以做什么

- 建立预审项目：记录公司、T0、场景、行业、两个年度和金额单位（默认**元**）。  
- 一键载入标准股份开发样例，支持 2025/2024、2024/2023、2023/2022；每组数字、**evidence_id**、文件名与页码整组绑定。  
- 修改公司或年度时，内置样例整组切换；无对应样例时清空旧资料并阻断计算。  
- 录入 R1 四项数字，并为每个数字填写 **来源编号（evidence_id）** 与完整来源定位。  
- 由程序固定复算：营业收入增速、应收账款增速、两者差额（百分点）。  
- 四类异常明确拦截并提示：  
  1. 必需字段缺失  
  2. 年份错位（不连续 / 与数字绑定不一致）  
  3. 除数为零（上年金额为 0）  
  4. 缺少来源编号或来源定位不完整  
- 风险卡展示现象、进一步了解原因、正常解释、资料缺口、待索取资料与来源回指。  
- 所有输入只保存在当前浏览器 `localStorage`（键名 `audittrace_week2_state_v3`）。

## 当前还不是什么

- 不是比赛最终提交网页；是 W2 / G1 开发预览。  
- 没有冻结正式案例，没有接入大模型。  
- R1 仅按增速差方向筛查，不设风险等级与固定阈值；周转天数未启用。  
- A 的 R1 v0.2 专业定稿、B 的交叉复核签字仍可能进行中——页面实现 ≠ 专业已复核。  
- 不认定舞弊、不出具审计意见、不提供投资建议。

## R1 固定计算（与分工书 / 计划书一致）

- 营业收入增速 =（本年营业收入 − 上年营业收入）÷ 上年营业收入  
- 应收账款增速 =（本年应收账款 − 上年应收账款）÷ 上年应收账款  
- 两者差额 = 应收账款增速 − 营业收入增速（以百分点显示）  
- 触发方向：应收增速 > 收入增速 → 候选现象；**不设固定百分点阈值**

## 开发样例预期复算（单位：元）
