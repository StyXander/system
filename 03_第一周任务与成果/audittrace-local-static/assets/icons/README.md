## 使用建议

- 深色网页上直接使用透明 PNG，不再增加有色底板。
- 卡片图标建议显示为 96–160px；标题旁图标建议显示为 40–64px。
- 不要在图片内部叠加文字，中文标题放在 HTML 中，保证清晰度和可访问性。
- 这是项目插画资产，不代表对应功能已经正式实现或完成验证。
