# 审迹智链网页开发提示词

> 用途：后续把 A、B、C 的真实交付接进本周网页。以下提示词可以复制给 Codex 或 Gemini。Gemini 看不到本机路径，使用 Gemini 时只上传必要文件。

## 提示词 1：先说明项目边界

```text
你正在协助“审迹智链（AuditTrace）”竞赛项目。核心用户是会计师事务所审计项目组，使用场景限于业务承接、续聘复核和审计计划阶段。系统仅用公开资料形成收入确认及销售与收款循环的待核查线索、证据缺口和待索取资料清单，不认定舞弊、不形成审计意见、不提供投资建议。

当前只修改本次上传的 prototype 文件，不使用其他旧项目代码，不编造公司数字、页码、案例、规则阈值或实验结果。凡是尚未接入的内容，请明确显示“待接入”或“待人工确认”。
```

## 提示词 2：接入 A 的 R1 规则

```text
请读取我上传的 A_R1规则说明_v0.1 和现有 prototype/index.html、app.js、styles.css。

任务：
1. 对照 A 的原文列出网页现有字段是否足够；
2. 只接入 A 明确写出的公式和触发条件；
3. 如果 A 写“阈值待确认”，代码也必须保持“待确认”，不得自定 10%、20% 等数字；
4. 保留“正常解释、证据缺口、待索取资料、人工复核”四部分；
5. 用纯 JavaScript 实现，并在关键判断处写中文注释；
6. 修改后说明改了哪些文件，并给出人工测试步骤。

不要扩展 R2—R8，不要把候选现象写成舞弊或错报结论。
```

## 提示词 3：接入 B 的真实年报数据

```text
请读取我上传的 B_年报数据样例_v0.1.xlsx 和现有 prototype 网页。

先检查 Excel 是否至少含有：字段、年度、数值、单位、文件名、披露日期、PDF页码、印刷页码、原文或表格名称。不得根据常识补齐缺失数字或页码。

如果四个核心数字及来源信息完整，请把数据转换为网页可读取的结构化文件；如果任何一项不完整，请保持缺失并列出需要 B 补充的内容。网页展示时保留人工核对状态，不能把“已导入”等同于“已复核”。

优先选择简单、可重复的导入方式。若要新增 CSV/JSON，请同时写清导出步骤和字段映射。不要读取或展示后续处罚、问询回复、监管结论等 T1 资料。
```

## 提示词 4：让 C 检查网页文字

```text
请以会计师事务所审计项目组成员的视角，检查我上传的三个网页页面和 C_三个页面文字_v0.2。

只检查：
1. 每个按钮点下去会发生什么，是否一眼能懂；
2. 数据缺失时提示是否明确；
3. 风险卡是否同时包含正常解释、证据缺口和待索取资料；
4. 是否误用了“发现舞弊、公司造假、审计结论、投资建议”等越界表达；
5. 业务承接、续聘复核、审计计划三个场景的文字是否混用。

请按“页面位置—原文字—建议文字—修改原因”输出。不要修改公式，不要新增业务结论。
```

## 提示词 5：排查网页打不开或按钮失效

```text
请检查我上传的 index.html、styles.css、app.js。网页是无依赖的本地静态原型，应支持直接打开 index.html。

请依次检查：
1. HTML 引用的 CSS、JS 文件名是否正确；
2. app.js 是否有语法错误；
3. JavaScript 使用到的每个 id 是否存在；
4. 三个页面切换、保存项目、保存数据、清空内容和保存复核说明是否正常；
5. 四个数字不齐全或上年数为 0 时是否停止计算；
6. 用户输入是否在插入 HTML 前转义。

先报告问题和复现步骤，再给最小修改。不要重写整个界面，也不要加入外部依赖。
```

## 提示词 6：以后接入大模型时使用，不是本周任务

```text
请为现有 prototype 设计“未来接入大模型”的最小接口方案，本次只写接口说明，不调用模型、不生成结果。

要求模型只负责：把已经通过来源校验的结构化事实整理成候选解释、反证问题和证据缺口。增长率、阈值、页码完整性和公式复算必须由程序完成。输出必须是固定 JSON，引用现有 evidence_id；没有证据时必须返回 UNKNOWN。任何内容都要经过人工复核后才能进入风险备忘录。

请给出输入 JSON、输出 JSON、失败处理和人工闸门，不要声称模型效果已经验证。
```

## 使用提醒

- `项目参考文献与理论依据_v0.1.md` 是 Gemini 生成的候选清单。在回到论文、准则或正式网页原件核验前，不要把其中的作者、年份、结论、页码或链接写入正式材料。
- 不要把旧 FINTEL 项目的代码、测试、演示或结论接入本项目。
- 发送给 Gemini 时不要上传密钥、个人信息、客户资料、整个工作区或未来 T1 答案资料。
