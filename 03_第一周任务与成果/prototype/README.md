# 审迹智链第一周网页启动说明

## 这是不是最终提交网页

不是。当前根目录 `index.html` 是本周统一使用的 **M0 开发预览与功能验收入口**，负责项目设定、年报资料预检和 R1 风险卡草稿三步。它不是最终提交页面。

**三套结构重做方向（供团队选择，尚未定稿）**见：

`prototype/directions/README.md`

- A 专业审计工作台  
- B 克制金融科技  
- C 证据链风险路径  

每套均为完整可下载的 HTML/CSS/JS；计算口径未改。团队未选定方向前，以根目录 `index.html` 作为本周功能验收入口，不同时维护多套业务逻辑。改版前浅色原版另存于 `backup_v0.3_改版前原版/`。

最终可提交/演示版本还需要在 W10 前接入并冻结真实规则、开发/演示案例、模型或经核验缓存、人工确认和导出结果，再按照主办方最新要求验收。当前页面已经明确标注“非最终提交版本”，不能把视觉完成度等同于系统已经实现或验证。

## 最快打开方法

1. 打开本文件所在的 `prototype` 文件夹。
2. 双击 `index.html`。
3. 浏览器出现“新建预审项目”页面后，即表示启动成功。

本版不需要安装 Python、Streamlit 或其他软件，也不需要联网。填写的内容只保存在当前浏览器的本地存储中，不会自动上传。

## 三个页面怎么用

1. **新建预审项目**：填写公司名称、分析截止日、使用场景、年份和金额单位。
2. **年报数据预检**：把 B 从正式年报核对出的四个数字和来源位置逐行填入。
3. **R1 风险卡草稿**：数字齐全后自动计算收入增长率、应收账款增长率及两者差额；四项来源位置也补齐后，才生成现象描述草稿。

如果直接双击后浏览器限制本地文件，可在 `prototype` 文件夹打开终端，运行：

```powershell
python -m http.server 8000
```

再在浏览器访问 `http://localhost:8000`。如果电脑没有 Python，优先使用双击打开方式，不必为了本周任务安装环境。

## 本版已经能做什么

- 三个页面可以切换；
- 项目、数据和人工复核说明可在本地保存；
- `data-schema.json` 已明确项目、四项数据、来源定位和人工复核字段；
- 四个数字齐全后，可按固定公式计算两个增长率；四项来源位置完整后才显示候选风险卡；
- 可记录来源文件、披露日期、PDF 页码、印刷页码和原文位置；
- 只在“审计计划”场景显示候选认定和程序；
- 没有数据时保持空白，不用假数字生成结果。

## 本版还没有做什么

- 尚未接入 A 的正式 R1 提醒阈值，因此只展示差额方向，不自动认定风险等级；
- 尚未接入 B 的正式年报数据文件，因此当前需要人工录入；
- 尚未接入大模型、PDF 自动解析、T0/T1 案例或正式实验；
- 不是正式产品，也不能输出舞弊认定、审计意见或投资建议。
