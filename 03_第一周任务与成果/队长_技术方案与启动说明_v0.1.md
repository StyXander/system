## 1. 极简网页技术栈建议

根据《计划书_V2》第11章的推荐，为了在几天内搭出界面且不搞复杂配置，推荐使用 **Streamlit**。
它是一个Python库，可以只用Python代码写出带侧边栏、表单和数据表格的网页，非常适合“低代码Web界面”的定位。

**代码目录规划建议**：
在工作区内新建 `prototype/` 文件夹：
```text
plan/outputs/数智会计竞赛/
└── prototype/
    ├── app.py                 # Streamlit网页主程序
    ├── requirements.txt       # 写上 streamlit 和 pandas
    └── (等B做完后把 B_年报数据样例_v0.1.xlsx 放在这里读取)
```

## 2. 网页内部需要保存的核心字段

为了配合A的R1规则和B收集的数据，你的程序里（可以用 `pandas.DataFrame` 存，或者简单的字典字典）至少需要定义这些字段：

- **基础信息**：
  - `company_name`: 公司名称
  - `analysis_date`: 分析截止日 (T0)
- **财务数据（B负责提供真实值）**：
  - `revenue_current`: 本年收入
  - `revenue_prev`: 上年收入
  - `ar_current`: 本年应收账款
  - `ar_prev`: 上年应收账款
- **元数据（溯源用，必须有）**：
  - `source_file`: 来源文件名
  - `pdf_page`: PDF页码
- **程序计算的衍生字段（由你的代码计算，不是B去找）**：
  - `revenue_growth_rate`: 收入增长率 = (本年收入-上年收入) / 上年收入
  - `ar_growth_rate`: 应收账款增长率 = (本年应收账款-上年应收账款) / 上年应收账款
