# 审迹智链（AuditTrace） - 页面文字（v0.1）

> **说明**：本文件为队员C第一周任务交付物，包含了新建项目、年报数据预检、风险卡草稿三个页面的实际文案，队长可直接复制到前端代码中。内容严格遵循了《详细项目计划书_V2》中的审计师专业术语及输出边界限制。

## 页面1：新建预审项目

**页面标题：** 新建预审项目

**表单字段：**
1. **公司名称**（输入框，例如：XXX股份有限公司）
2. **分析截止日（T0）**（日期选择器，例如：2026-06-30）
3. **分析场景**（下拉菜单：新客户业务承接、续聘复核、审计计划）
4. **所属行业**（下拉菜单或输入框）

**操作按钮：**
- **[开始分析]**

**底端提示语（非常重要，必须展示）：**
> **⚠️ 提示：** 当前系统仅使用截止分析日已公开的年报、公告等资料形成待核查线索。本系统输出为预审风险备忘录、待核查事项和待索取资料清单，**不形成审计结论，不认定舞弊，不提供投资建议。** 任何风险线索均须保留正常解释和资料缺口。

## 页面2：年报数据预检

**页面标题：** 核心数据与来源预检

**数据表列名（表头）：**
- 字段名称（如：本年收入、上年应收账款）
- 数值及单位（如：10,000.00 万元）
- 所属年度（如：2025年）
- 资料来源文件名（如：2025年年度报告.pdf）
- 披露日期（如：2026-04-20）
- 定位信息（PDF页码 / 印刷页码 / 原文表名）
- 数据获取状态

**数据获取状态（枚举词）：**
- 🟢 **已找到并核验**
- 🟡 **部分找到 / 待人工补录**
- 🔴 **未找到 / 不可得 / 资料依据缺口**

**数据缺失时的提示语：**
> **提示：** 发现部分公开资料数据缺失或未能解析。系统不会进行猜测或使用未经核验的第三方摘要补齐。请人工查阅原件并在下方补录，或在分析中标记该项为“资料依据缺口”。

## 页面3：风险卡草稿（Top 5 待核查事项）

**页面标题：** 风险卡草稿（R1：应收与收入背离）

**小标题及文字内容模板：**

1. **🚩 发现了什么现象（异常信号）：**
   - *（前端展示示例）* 2025年度，公司应收账款增速（[X]%）显著高于营业收入增速（[Y]%）。

2. **🔎 为什么需要进一步了解（风险机理）：**
   - *（前端展示示例）* 收入的增长未带来相应的现金流入。上述变化可能表明收入增长的质量下降，或者履约、结算与回款条件之间存在不一致。涉及的候选认定包括：收入发生认定，以及应收账款/合同资产的存在、权利和义务、计价和分摊认定。

3. **⚖️ 可能的正常原因（反证解释候选）：**
   - *（前端展示示例）* 业务扩张导致新增大客户、给予核心客户更宽松的信用政策、结算周期改变、或行业账期整体拉长等。

4. **📄 目前缺少什么资料（资料依据缺口）：**
   - *（前端展示示例）* 仅通过T0前公开资料，无法获取前五大客户的具体信用期变化明细，以及期后回款的实际流水情况。

5. **📥 建议向客户索取什么资料（场景化后续动作）：**
   - *（前端展示示例）* 建议向客户索取以下资料以作进一步核查：1) 账龄明细表；2) 期后回款记录；3) 造成本年应收激增的主要合同摘要及结算条款；4) 信用政策变更说明。

6. **🔗 资料原件和计算位置：**
   - **本年收入：** [数值] 万元，来源于 [[来源文件]]，第 [X] 页
   - **上年收入：** [数值] 万元，来源于 [[来源文件]]，第 [X] 页
   - **本年应收账款：** [数值] 万元，来源于 [[来源文件]]，第 [X] 页
   - **上年应收账款：** [数值] 万元，来源于 [[来源文件]]，第 [X] 页
   - **计算逻辑：** 收入增长率 = (本年收入-上年收入) ÷ 上年收入；应收账款增长率 = (本年应收账款-上年应收账款) ÷ 上年应收账款。
